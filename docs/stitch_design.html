Tài liệu đặc tả Frontend Implementation (State Matrix)
Component: <CreateMeetingModal />
1. Quản lý State:
  • title: string (Required)
  • description: string (Optional)
  • meetingDate: string (YYYY-MM-DD)
  • startTime & endTime (HH:mm)
  • duration: Computed state
2. Quy tắc Validation:
  • Title không được bỏ trống hoặc chỉ chứa khoảng trắng.
  • endTime > startTime trong cùng ngày.
  • Tự động format thời lượng: "1 giờ 30 phút".
3. Trạng thái nút Submit:
  • Hover: bg-blue-700
  • Loading: Spinner SVG, text "Đang tạo cuộc họp..."
  • Disabled: opacity-50 pointer-events-none
