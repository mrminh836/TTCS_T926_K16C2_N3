TC_AUTH_JWT_006 Xác thực JWT Token
Auth / JWT Middleware 		Kiểm tra hỗ trợ tiền tố Authorization Header chữ thường 'bearer <token>' (RFC 6750 Case-Insensitivity) Có token hợp lệ. Gửi header với prefix chữ thường: 'bearer <token>'. 1. Gửi request GET /api/auth/me. 2. Header: 'Authorization: bearer eyJhbGci...'. 3. Quan sát kết quả. Header: 'Authorization: bearer eyJhbGci...' Theo RFC 6750, auth scheme nên được xử lý case-insensitive hoặc chấp nhận 'bearer '.
